# VEINMusic для Windows

Приложение на [Tauri 2](https://tauri.app): сайт VEINMusic в отдельном окне, значок в трее и скробблинг всего, что играет на компьютере.

## Что умеет

- **Скробблинг из системной панели медиа Windows.** Читает всё, что показывает панель (System Media Transport Controls):
  - Spotify — без платного API Spotify;
  - приложение Яндекс Музыки;
  - AIMP, foobar2000, VLC, Apple Music, MusicBee;
  - вкладки браузеров.

  Прослушивания отправляются в `POST /api/scrobble`, как у расширения: сразу при смене трека, паузе и продолжении, а пока трек играет — раз в 15 с. Время прослушивания считает сервер.
- **Источники можно включать по отдельности.**
  - Яндекс Музыка выключается сама, если на сайте уже подключён Яндекс: сервер скробблит его напрямую, и прослушивания задвоились бы.
  - Браузеры по умолчанию выключены: их скробблит расширение VEIN.
- **Подключение аккаунта по коду**, как у расширения:
  - приложение получает код (`/api/devices/code`) и открывает страницу `/link` в своём окне;
  - после подтверждения на сайте получает собственный ключ;
  - ключ хранится в диспетчере учётных данных Windows, отозвать его можно на сайте: «Настройки → Безопасность и данные».
- **Трей.**
  - Закрытое окно не останавливает приложение, оно работает в трее и по умолчанию запускается вместе с Windows (свёрнутым).
  - В меню трея: что сейчас играет, выключатель скробблинга, настройки, проверка обновлений.
- **Обновления.** Приложение раз в 6 часов проверяет релизы `desktop-v*` на GitHub и предлагает скачать новую версию.
- **Статус в Discord** — если при сборке задан `VEIN_DISCORD_CLIENT_ID` (см. ниже). Без него пункт скрыт.

## Устройство

| Файл | Что внутри |
|---|---|
| `src-tauri/src/lib.rs` | окна, трей, команды окна настроек, подключение по коду, цикл скробблинга |
| `src-tauri/src/media.rs` | чтение панели медиа Windows (`windows` crate) |
| `src-tauri/src/tracker.rs` | чистая логика: какой плеер выбрать и когда отправлять отчёт (юнит-тесты) |
| `src-tauri/src/api.rs` | API VEINMusic и проверка релизов на GitHub |
| `src-tauri/src/settings.rs` | настройки (JSON в папке приложения) и ключ в хранилище Windows |
| `src-tauri/src/discord.rs` | статус в Discord |
| `ui/` | окно настроек (HTML/CSS/JS без сборщика) |
| `src-tauri/installer/` | оформление установщика в цветах сайта: `hooks.nsh` (тёмная тема Modern UI), картинки `sidebar.bmp` и `header.bmp` |

Окно сайта открывает удалённую страницу и доступа к командам приложения не имеет: они разрешены только локальному окну настроек (`capabilities/settings.json`, плюс проверка метки окна в каждой команде).

## Сборка

Нужны Windows, [Rust](https://rustup.rs), Node.js 22 и WebView2 (есть в Windows 10/11).

```powershell
cd desktop
npm ci
npx tauri dev     # запуск для разработки
npx tauri build   # установщик: src-tauri/target/release/bundle/nsis/*.exe
```

Для работы с локальным сервером задайте `VEIN_API_URL=http://localhost:8000` и `VEIN_SITE_URL=http://localhost:3000`.

Картинки установщика нарисованы в `src-tauri/installer/art.html`. Чтобы поменять их, снимите в браузере блоки `#side` (164×314) и `#head` (150×57) при масштабе 100% и сохраните как 24-битные BMP.

Юнит-тесты и линтер:

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
```

## Выпуск версии

1. Поднимите версию в `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` и `package.json`.
2. Создайте тег `desktop-vX.Y.Z` (с той же версией): командой `git push origin desktop-vX.Y.Z` или на GitHub через Releases → Draft a new release.
3. Workflow `Desktop app (Windows)` соберёт установщик (около 12 минут) и приложит его к релизу — создаст релиз сам или дополнит созданный вручную. Приложения у пользователей увидят его при следующей проверке обновлений.

Установщик не подписан: при первом запуске Windows SmartScreen покажет предупреждение («Подробнее → Выполнить в любом случае»). Чтобы его убрать, нужен сертификат подписи кода.

## Статус в Discord

1. Создайте приложение на [discord.com/developers](https://discord.com/developers/applications) с названием VEINMusic.
2. В разделе Rich Presence → Art Assets загрузите логотип с именем `logo`.
3. Скопируйте Application ID в переменную репозитория `VEIN_DISCORD_CLIENT_ID` (Settings → Secrets and variables → Actions → Variables).

Следующая сборка покажет пункт «Статус в Discord».
