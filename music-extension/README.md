# VEINMusic Extension

История прослушиваний из Яндекс Музыки, Spotify, YouTube Music, VK, SoundCloud,
Apple Music и Звука в вашем аккаунте [VEINMusic](https://music.vein.guru).
Разметка музыкальных сервисов может меняться; поддержка веб-плеера не означает
поддержку его мобильного или настольного приложения.

Интерфейс расширения следует языку браузера: русский в русском браузере,
английский во всех остальных (English is the default; the extension follows the
browser language). Тексты находятся в `_locales/<язык>/messages.json`; новый
язык добавляется отдельной папкой с тем же набором ключей.

## Скачать

Описание расширения и актуальный статус установки: <https://music.vein.guru/extension>.

**[Открыть выпуск 1.5.1](https://github.com/Peaostrel/VEINMusic/releases/tag/extension-v1.5.1)** — скачивание без регистрации на GitHub.

- Chrome / Edge / Brave / Яндекс Браузер: `VEINMusic-extension-chromium-1.5.1.zip`.
- Firefox 142+: `VEINMusic-extension-firefox-1.5.1.zip`.
- `SHA256SUMS.txt`: контрольные суммы пакетов.

### Chromium

1. Скачайте и распакуйте ZIP в постоянную папку. Не удаляйте её после установки.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`).
3. Включите «Режим разработчика» → «Загрузить распакованное расширение».
4. Выберите папку, внутри которой лежит `manifest.json`.
5. Закрепите VEINMusic на панели расширений.

Это установка через режим разработчика, без автоматических обновлений.
Пакет подходит и для загрузки в Chrome Web Store; публикация в магазине требует
аккаунта разработчика и проверки Google. ZIP не является установкой в один клик.

### Firefox

1. Скачайте и распакуйте Firefox ZIP.
2. Откройте `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение».
3. Выберите `manifest.json` из распакованной папки.

**Этот пакет ещё не подписан Mozilla.** Временное дополнение удаляется после
перезапуска Firefox. Для постоянной установки нужна подписанная версия через
AMO или подписанный XPI. Не отключайте проверку подписей ради этого пакета.

## Подключить

1. В окне расширения отметьте «Передавать прослушивания в VEIN».
2. Нажмите «Подключить через сайт», войдите в VEIN и подтвердите короткий код.
3. Откройте музыкальный веб-плеер и включите трек. Если вкладка уже была открыта
   до установки или обновления расширения, перезагрузите её.
4. «Проверить связь» проверяет ключ без добавления тестового прослушивания.

Снимите галочку, чтобы приостановить передачу и удалить очередь повторной
отправки. «Отключить» также удаляет ключ из расширения. Чтобы отозвать ключ на
сервере, удалите устройство в настройках VEIN → «Безопасность и данные».
После обновления с 1.4.3 подтвердите передачу галочкой: она выключена по умолчанию.

## Какие данные используются

После подключения передаются метаданные трека, обложка, ссылка, прогресс и
состояние воспроизведения. При кратком сбое расширение сохраняет последнее
состояние каждого сервиса и повторяет передачу. Сигналы старше 35 секунд
удаляются: API принимает живое состояние, поэтому старый трек нельзя выдавать
за текущий. Это не импорт прослушиваний, сделанных без связи с VEIN.
Очередь привязана к ключу аккаунта и ограничена 500 сигналами. До включения
передачи данные не сохраняются и не отправляются.
Общая история браузера, сообщения и пароли музыкальных сервисов не читаются.
Политика: <https://music.vein.guru/privacy>.

В окне расширения отображается именно результат приёма события: например,
успех, выключенная интеграция, приватная сессия или необходимость обновить
ключ. «Проверить связь» проверяет только доступ к API; он не подтверждает, что
страница музыкального сервиса передаёт треки.

Права `storage` и `alarms` нужны для локальных настроек и повторной отправки.
Доступ ограничен перечисленными музыкальными плеерами, сайтом и API VEIN.
Публичные пакеты не запрашивают доступ к localhost и произвольным поддоменам VEIN.

## Сборка и проверка

```sh
node --test music-extension/tests/*.test.cjs
python3 scripts/package_extension.py
npx --yes web-ext@10.7.0 lint --source-dir dist/extension/firefox --warnings-as-errors
```

Пакеты находятся в `dist/extension`. Тесты, локальные настройки и другие файлы
репозитория в ZIP не включаются. Один manifest преобразуется в отдельные
Chromium service-worker и Firefox background-scripts manifests.

## Кнопка установки на сайте

Страница `/extension` по умолчанию показывает кнопку «Установить в Firefox»
со ссылкой на опубликованное дополнение:
https://addons.mozilla.org/en-US/firefox/addon/vein-music-tracker/.
При необходимости адрес можно переопределить через `FIREFOX_ADDON_URL` в `.env`
развёртывания: допускается только HTTPS-карточка `addons.mozilla.org/.../firefox/addon/.../`.
Пересоздайте контейнер frontend, чтобы применить переменную. Страница читает её
при запросе; пустое значение использует опубликованный адрес по умолчанию,
а неверный непустой адрес оставляет статус «Скоро в Firefox Add-ons».
Неподписанный ZIP не используется для постоянной установки.

Когда карточка в Chrome Web Store опубликована, задайте `CHROME_EXTENSION_URL`
(например `https://chromewebstore.google.com/detail/<id>`) и пересоздайте
контейнер frontend: на странице появится кнопка «Установить в Chrome».
Пустое или неверное значение кнопку не показывает.

CI дополнительно устанавливает Chromium-пакет и проверяет popup, передачу
из веб-плеера со строгой CSP, проверку связи и остановку после отключения.
Публикация на GitHub запускается только на ветке VEIN после этих проверок;
повторная публикация уже выпущенной версии не заменяет её архивы.
