Проверенный пакет браузерного расширения **VEINMusic 1.5.0**.

Скачать архивы ниже можно без регистрации на GitHub.

- **Chrome / Edge / Brave / Яндекс Браузер**: скачайте `VEINMusic-extension-chromium-1.5.0.zip`, распакуйте, откройте страницу расширений, включите режим разработчика и выберите «Загрузить распакованное расширение» → папку с `manifest.json`.
- **Firefox 142+**: `VEINMusic-extension-firefox-1.5.0.zip` предназначен для временной установки через `about:debugging`. Это **неподписанный** пакет: после перезапуска дополнение удалится. Для постоянной установки нужна публикация/подпись Mozilla.
- `SHA256SUMS.txt` содержит контрольные суммы архивов.

В окне расширения включите «Передавать прослушивания в VEIN», нажмите «Подключить через сайт» и подтвердите код. Уже открытые музыкальные вкладки перезагрузите.

В этом выпуске:

- Явное включение передачи; до подключения прослушивания не сохраняются и не отправляются.
- Очередь привязана к ключу аккаунта, очищается при отключении и не переносится между аккаунтами.
- Проверка связи не добавляет выдуманный трек.
- Общий опрос подключения исключает гонку между popup и фоновым таймером.
- Трекер загружается через MAIN world; отдельные пакеты для Chromium и Firefox.
- Права публичных пакетов ограничены музыкальными сервисами и VEIN; localhost исключён.

[Подробная инструкция](https://github.com/Peaostrel/VEINMusic/blob/VEIN/music-extension/README.md) · [Конфиденциальность](https://music.vein.guru/privacy)

Это публичные ZIP-пакеты, **не публикация в Chrome Web Store или Firefox Add-ons**. Установка Chromium пока требует режима разработчика и не обновляется автоматически.
