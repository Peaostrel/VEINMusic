## 1.5.5

Добавлен Звук (zvuk.com): трек, обложка и позиция берутся из системной
панели медиа плеера, как у Spotify и Apple Music.

## 1.5.4

Firefox: прослушивания из Spotify, YouTube Music, VK, SoundCloud и Apple Music
снова передаются. Сообщения трекера страницы отбрасывались, потому что глобальный
объект content script в Firefox не совпадает с окном страницы. Chromium-сборка
не менялась по поведению.

Новый вид окна расширения в стиле сайта VEIN: переключатель передачи, карточка
аккаунта, последний трек с цветным статусом приёма, код подключения крупным
шрифтом, ручной ввод API-ключа свёрнут.

## 1.5.3

В popup добавлена диагностика последнего события: версия расширения, трек,
пауза/воспроизведение, позиция, задержка доставки и время обработки сервером.
Каждое событие получает стабильный идентификатор и метку времени клиента.

## 1.5.2

Playback events (pause, resume, seek and media changes) are captured immediately.
DOM changes trigger a batched refresh; a 250 ms safety poll covers players that
expose no events. Normal progress heartbeats stay limited to once per 5 seconds.
The extension sends an explicit `player_position` flag only with a known player
clock; API support is required to show that clock separately from listening credit.
Live positional reports take priority over fresh cloud state for the same track.
No permissions or data collection categories were added.

Проверенный пакет браузерного расширения **VEINMusic 1.5.1**.

Скачать архивы ниже можно без регистрации на GitHub.

- **Chrome / Edge / Brave / Яндекс Браузер**: скачайте `VEINMusic-extension-chromium-1.5.1.zip`, распакуйте, откройте страницу расширений, включите режим разработчика и выберите «Загрузить распакованное расширение» → папку с `manifest.json`.
- **Firefox 142+**: `VEINMusic-extension-firefox-1.5.1.zip` предназначен для временной установки через `about:debugging`. Это **неподписанный** пакет: после перезапуска дополнение удалится. Для постоянной установки нужна публикация/подпись Mozilla.
- `SHA256SUMS.txt` содержит контрольные суммы архивов.

В окне расширения включите «Передавать прослушивания в VEIN», нажмите «Подключить через сайт» и подтвердите код. Уже открытые музыкальные вкладки перезагрузите.

В этом выпуске:

- Проверяется JSON-статус приёма, включая ответы HTTP 200 с отказом; причина видна в окне расширения.
- Повторная отправка не возвращает старый трек поверх нового; после сбоя восстанавливается последнее свежее состояние.
- Остановленная вкладка сообщает паузу один раз и больше не перебивает активный плеер.
- Неинициализированные аудиоэлементы и неизвестная длина потока не блокируют передачу.
- Явное включение передачи; до подключения прослушивания не сохраняются и не отправляются.
- Очередь привязана к ключу аккаунта, очищается при отключении и не переносится между аккаунтами.
- Проверка связи не добавляет выдуманный трек.
- Общий опрос подключения исключает гонку между popup и фоновым таймером.
- Трекер загружается через MAIN world; отдельные пакеты для Chromium и Firefox.
- Права публичных пакетов ограничены музыкальными сервисами и VEIN; localhost исключён.
